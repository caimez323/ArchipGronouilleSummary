Setup Hexcells Infinite Archipelago

Installation et de lancement de mod Hexcells Infinite en multiworld Archipelago.

⚙️ Configuration
1
Installer et lancer Hexcells Infinite au moins une fois, puis fermer le jeu.
2
Télécharge et installe BepInEx win_x86 v5. Attention : besoin de x86, pas x64
3
Extract BepInEx dans les dossiers du jeu steamapps/common/Hexcells Infinite
4
Lance le jeu une fois puis referme (pour lancer BepinEx).
5
Extract the Hexcells Infinite Randomizer folder into the BepInEx/plugins folder.
6
Run the game to generate the APInfo file in your game folder, then edit the file to match your Archipelago lobby settings.
7
Restart the game after editing the APInfo file, and have fun!
